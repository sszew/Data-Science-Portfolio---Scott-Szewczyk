# Data Science Portfolio -- Scottie Szewczyk


Welcome to my Data Science portfolio! This page contains links to samples of my personal projects using various data analytics tools.

## Projects

1. *Developing a Heart Disease Prediction Model (UCI Heart Disease Dataset)*
   - https://github.com/sszew/heart_disease_machine_learning

   - **Skills**: Machine learning, Logistic regression, Random forest, Statistical modeling, Statistical reasoning, Exploratory data analysis (EDA)
   
2. *Modeling U.S. County-level Cancer Mortality Rates: an Ordinary Least Squares (OLS) Linear Regression Model*
   - https://github.com/sszew/Linear-Regression

   - **Technology**: R
   - **Skills**: Linear regression, Statistical modeling, Statistical reasoning, Exploratory data analysis (EDA)
